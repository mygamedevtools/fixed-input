Input Overlay Mockups

Four ways to show the same thing without taking the screen. Each runs the real logic at 50 Hz: wrapping subtraction in Peek, peek to test and consume to act, a 14-step attack buffer that chains, and a 6-step jump buffer.

A · Corner ribbon

always on · 368×150

Tick, live key caps, one scrolling lane per intent, and a frame strip underneath: measured fps, the fixed rate, a frame-time graph, and the ratio between them.

The rate control is the part that earns its space. Cap to 12 fps and the loop really does run less often, so steps pile up between frames and the ratio flips to steps/frame in amber. Watch the character keep walking at exactly the same speed and you have proved frame independence rather than assumed it.

B · Input column

always on · fighting-game read

One row per press, newest on top: what was pressed, the step it bound to, and how it resolved.

The most legible for why did that press not come out, which is the question this package exists to answer. Costs a strip of screen edge.

C · World tag

anchored to the character

Floats above whoever it watches, so with several characters you can see which agent is doing what without picking them out of a list.

The only option that scales past one subject. Clutters fast if everything is tagged.

D · Drawer

collapsed 34px · opens on F3

A thin bar with the tick and a lit pip per intent. Open it for the three stages and the transport.

Costs almost nothing until you need it, and holds everything when you do.

What I would ship: A and D together, with C opt-in per character. The ribbon answers is input flowing at a glance, the drawer answers why not on demand, and the tag answers which one when there are several.

B is the strongest single view, but it only fits one surface. It belongs inside the expanded drawer as a tab rather than as the always-on layer. Try A+C+D above to see the combination.

In Unity the two controls map to Application.targetFrameRate with vsync off, and Time.timeScale. Both are global, so the overlay has to hand them back on disable or it leaves the game it was inspecting running at a twentieth speed.
